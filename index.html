Get started

Pull and run.

LatentSync uses a source video and driving audio.

Terminal
vrhino pull vrhino/latentsync-1.6:1.0.0

vrhino run vrhino/latentsync-1.6:1.0.0 \
  --video input.mp4 \
  --audio driving.wav \
  --output output.mp4

One Native runtime.

Versioned model packages define frozen graphs, configuration, and bounded workflows.

Self-contained.

No Python, PyTorch, Diffusers, Conda, CUDA Toolkit, cuDNN, or system FFmpeg installation.

Clear boundary.

No hosted model weights. Users acquire upstream assets locally when applicable.

Platform Linux x86_64 + compatible NVIDIA GPU + Driver + VRhino
