Pull and run

Pull the exact package, then generate an MP4 from a text prompt.

Terminal
vrhino pull vrhino/wan2.1-t2v-1.3b:1.0.0

vrhino run vrhino/wan2.1-t2v-1.3b:1.0.0 \
  --prompt "a rhinoceros walking through a snowy forest" \
  --output wan-output.mp4

Distribution and license

The VRhino release contains no Wan model weights or converted Wan .vrm weights. The pull command obtains original artifacts from the fixed official Wan-AI/Wan2.1-T2V-1.3B revision; conversion and installation occur locally.

The fixed upstream source declares Apache License 2.0. Review the authoritative license before downloading, converting, or using the model.

Qualification scope

Support applies only to the exact 1.3B model package and its qualified default profile on Linux x86_64 with NVIDIA CUDA. It does not imply support for Wan 14B, Wan2.2, other Wan checkpoints, every NVIDIA GPU, or every Linux distribution. No exact minimum VRAM requirement is claimed.
