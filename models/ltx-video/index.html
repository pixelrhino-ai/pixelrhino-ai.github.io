Pull and run

Pull the exact package, then generate an MP4 from a text prompt.

Terminal
vrhino pull vrhino/ltx-video-v0.9.1:1.1.0

vrhino run vrhino/ltx-video-v0.9.1:1.1.0 \
  --prompt "a cat walking in snow" \
  --output output.mp4

Distribution and license

The VRhino release contains no LTX model weights or converted LTX .vrm weights. The pull command obtains original artifacts from the fixed Lightricks/LTX-Video revision; conversion and installation occur locally.

Review and comply with the version-specific upstream LTX v0.9.1 license. The VRhino binary license grants no model, training-data, input-content, output-content, or other upstream rights.

Qualification scope

Support is limited to this exact Public Alpha package path on the qualified Linux x86_64 NVIDIA CUDA platform. No performance figure or minimum VRAM requirement is asserted here.
