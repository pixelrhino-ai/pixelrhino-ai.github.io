Pull and run

Pull the exact package, then generate an MP4 from a text prompt.

Terminal
vrhino pull vrhino/mochi-1-preview:1.0.0

vrhino run vrhino/mochi-1-preview:1.0.0 \
  --prompt "a red panda runs through snow." \
  --output mochi-output.mp4

Distribution and license

The VRhino release contains no Mochi model weights or converted Mochi .vrm weights. The pull command obtains original artifacts from the fixed official genmo/mochi-1-preview revision; conversion and installation occur locally.

The fixed upstream model card declares Apache License 2.0. Review the authoritative model card and license before downloading, converting, or using the model.

Qualification scope

The qualified default preset is admitted only when VRhino’s planner sees at least 80 GiB of available device memory. This is the current support and admission threshold for that preset, not an empirically proven absolute minimum VRAM requirement.

Support applies only to this exact model package and default profile on Linux x86_64 with NVIDIA CUDA.
