Pull and run

Pull the exact Mode-C package, then provide a source video and driving audio.

Terminal
vrhino pull vrhino/latentsync-1.6:1.0.0

vrhino run vrhino/latentsync-1.6:1.0.0 \
  --video input.mp4 \
  --audio driving.wav \
  --output output.mp4

Mode-C distribution

Pixel Rhino does not distribute or host original model checkpoints, model weights, or converted VRhino model components. vrhino pull obtains the exact 12 upstream inference assets, verifies their fixed identities, converts them locally, and installs the immutable package. Conversion changes representation, not licensing.

Bounded workflow

The Public workflow uses MediaPipe BlazeFace Short Range and DWPose for face analysis and alignment instead of LatentSync’s optional InsightFace auxiliary weights. Internal alignment, mask, and sampling policy remain frozen by the package rather than exposed as general tuning controls.

Qualification scope

Qualified on an NVIDIA GeForce RTX 4090 D with the CUDA backend. Observed peak internal allocation was approximately 19.9 GiB for the qualification profile. This is an observation, not a minimum VRAM requirement or admission threshold.
