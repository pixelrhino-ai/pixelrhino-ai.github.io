Pull and run

Pull the exact Mode-C package, then provide a source video and driving audio.

Terminal
vrhino pull vrhino/musetalk-v1.5:1.0.0

vrhino run vrhino/musetalk-v1.5:1.0.0 \
  --video input.mp4 \
  --audio driving.wav \
  --output output.mp4

Mode-C distribution

Pixel Rhino does not distribute or host original model checkpoints or converted .vrm model components. vrhino pull obtains exact assets from official upstream sources, verifies their fixed identities, converts them locally, and installs the immutable package. Conversion changes representation, not licensing.

License and responsible use

MuseTalk model use remains subject to CreativeML OpenRAIL-M use-based restrictions. Other components carry MIT and Apache-2.0 terms, as itemized in the authoritative third-party notices. Users are responsible for lawful and consented use of video, faces, images, and audio. No upstream endorsement is implied.

Qualification scope

The package was qualified on an NVIDIA GeForce RTX 4090 D with the CUDA backend. One full-sample qualification observed approximately 6.27 GiB peak internal device allocation; this is an observation, not a minimum VRAM requirement.
